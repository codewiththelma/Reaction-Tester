# Reaction Tester  

A reaction speed testing game where users click as fast as possible when a shape appears on the screen. The project tracks the reaction time and provides feedback to the user. 

## Features  

- **Reaction Time Tracking**: Measures how quickly users click when the shape appears.  
- **Randomized Shape Appearance**: Shapes appear at different positions and intervals.  
- **Performance Feedback**: Displays reaction time to help users improve speed.  
- **Simple and Interactive UI**: Engaging design with smooth gameplay.  

## Technologies Used  

- **Languages**: HTML, CSS, JavaScript  
- No external libraries are needed, as the project runs on core web technologies.
